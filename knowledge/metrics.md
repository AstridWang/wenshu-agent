# 业务指标口径

本文件是问数 Agent 的指标知识库。Agent 回答问题时必须按这里的定义计算。
修改口径只需要改这个文件，不用动代码。

## 通用规则

- **订单状态**：`paid` 为有效订单，`refunded` 为已退款订单。库里没有未支付订单。
- **时间归属**：所有指标按下单日期 `order_date` 归属到月。退款也归到订单的下单月，不按退款日期归属。
- **默认时间范围**：问题没有指定时间时，用全部数据（2026-04 至 2026-09）。
- **渠道类型**：信息流投放、达人直播、短视频自播是付费渠道，有投放花费；老带新、自然流量是免费渠道，没有投放花费，不计算 ROI 和获客成本。
- **比率的展示**：退款率等比率用百分比，保留 1 位小数；ROI 保留 2 位小数；金额保留到元。
- **环比**：与上一个月比。**同比**：与去年同月比，本库只有 6 个月数据，同比算不了。

## 收入类

### GMV
- 别名：下单金额、成交总额、流水
- 定义：全部订单的金额合计，**含已退款订单**
- 计算：`SUM(amount)`

### 实收金额
- 别名：净收入、实际收入、销售额、营收
- 定义：有效订单的金额合计，**不含已退款订单**
- 计算：`SUM(CASE WHEN status='paid' THEN amount ELSE 0 END)`
- 说明：用户只说"销售额""收入""卖得好不好"而没有特别说明时，默认指实收金额

### 退款金额
- 定义：已退款订单的金额合计
- 计算：`SUM(CASE WHEN status='refunded' THEN amount ELSE 0 END)`

## 订单类

### 订单数
- 别名：下单量、成交单数
- 定义：全部订单的笔数，**含已退款订单**
- 计算：`COUNT(*)`

### 有效订单数
- 别名：付费订单数、净订单数
- 定义：未退款订单的笔数
- 计算：`SUM(CASE WHEN status='paid' THEN 1 ELSE 0 END)`

### 客单价
- 别名：单均金额、笔单价
- 定义：实收金额 ÷ 有效订单数
- 计算：`SUM(CASE WHEN status='paid' THEN amount ELSE 0 END) * 1.0 / SUM(CASE WHEN status='paid' THEN 1 ELSE 0 END)`
- 注意：不要用 `AVG(amount)` 对全部订单求平均，那样会把已退款订单算进去

## 退款类

### 退款率
- 别名：退费率、退单率
- 定义：退款订单数 ÷ 订单数，**按订单笔数算，不按金额算**
- 计算：`SUM(CASE WHEN status='refunded' THEN 1 ELSE 0 END) * 100.0 / COUNT(*)`
- 注意：这是默认口径。只有用户明确说"按金额"时才使用下面的退款金额率

### 退款金额率
- 定义：退款金额 ÷ GMV
- 计算：`SUM(CASE WHEN status='refunded' THEN amount ELSE 0 END) * 100.0 / SUM(amount)`

### 退款时长
- 定义：从下单到退款的天数
- 计算：`julianday(refund_date) - julianday(order_date)`，只对已退款订单计算

## 投放类

### 投放花费
- 别名：广告费、投放成本、消耗
- 定义：`ad_spend` 表中的 `spend`，按月、按渠道记录
- 注意：花费**没有拆到产品或学科**，所以任何"分产品""分学科"的 ROI、获客成本都算不了

### ROI
- 别名：投产比、ROAS、投放回报
- 定义：实收金额 ÷ 投放花费，**分子用实收金额，不用 GMV**
- 计算：先分别汇总某渠道某时间段的实收金额和投放花费，再相除
- 解读：ROI 小于 1 表示实收金额不足以覆盖投放花费
- 注意：只对付费渠道计算；订单表和花费表要先各自按月、渠道汇总再关联，直接关联会重复计算花费

### 获客成本
- 别名：CAC、单均获客成本、单个订单成本
- 定义：投放花费 ÷ 有效订单数
- 注意：这里按订单算而不是按用户算；只对付费渠道计算

### 投放效率
- 说明：这是一个笼统的说法。用户问"效率"时，同时看 ROI 和获客成本两个指标，并在结论里说明

## 数据不支持的指标

下面这些指标本库算不了，被问到时直接说明原因，不要估算：

| 指标 | 算不了的原因 |
|---|---|
| 分学科或分产品的 ROI、获客成本 | 投放花费只记录到渠道，没有拆到产品 |
| 复购率、LTV、留存 | 用户 ID 是随机生成的，不能代表真实的重复购买 |
| 利润、毛利、UE | 没有交付成本、人力成本等成本数据 |
| 同比 | 只有 6 个月数据 |
| 地域、年龄、设备等用户属性分析 | 没有用户属性表 |
| 完课率、到课率、续费率 | 没有学习行为和续费数据 |
| 转化率、线索成本 | 没有线索和流量数据，只有成交订单 |
